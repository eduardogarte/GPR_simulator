# GPR_simulator
Ground Penetrating Radar (GPR) is a simulator based on physical signal of a radar for mine applications. It takes a basic
comprehension of wave equations, it try to simulate the radar as soon as posible we can. It was a project which were a possible
real-world application.

## Installation
Use the conda package manager to install the required libraries.
```
conda env create -f gpr_env.yml
```
## Usage
It just needs to run the Demo_gpr.py file with the environment previously created. It will update with a parameterized version.
